# Contributing to soz-data-ai-lab

Thank you for your interest in contributing! This repository is focused on learning and documentation; contributions that add clear explanations, small runnable examples, or improvements to existing docs are very welcome.

How to contribute

- Fork the repository and create a feature branch for your change.
- Keep changes small and focused (one topic or example per PR).
- Include a short description in the PR explaining what you changed and why.
- Add or update README files for the area you change so other learners can follow.

Code style

- Prefer clear, well-commented examples over clever code.
- Include minimal instructions to run each example (required packages and commands).

License

Contact

If you have questions, open an issue or start a discussion in this repository.
