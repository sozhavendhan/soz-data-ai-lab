# AI Engineering - LLM quickstart

This note contains a short checklist for getting started with LLM experiments:

1. Pick a simple wrapper (OpenAI python client, or LangChain) and a small model.
2. Keep prompts short and include examples for few-shot learning.
3. For RAG, index documents with embeddings and build a retrieval step before generation.

See ai-engineering/rag/example_rag.md for a minimal RAG flow.
